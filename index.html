选择模型
Coding Agent 要先写 JSON 工具调用、再写一整个文件，格式一错就废。0.5B / 1B 级别的小模型基本做不了这个——建议至少 Coder 3B，或者直接用云端 / Ollama。数字是显存需求，不是下载大小。
任意 OpenAI 兼容接口（/chat/completions）。Key 只存在你浏览器的 localStorage，请求直接从浏览器发到你填的地址，不经过本站。思考型模型容易把 token 预算烧在看不见的推理上、正式输出为空，写代码建议用非思考的常规接口。
思考型模型会把 token 先花在看不见的推理上，难的轮次里正文可能为空、也很慢。BigModel：GLM-4.x 可用 {"thinking":{"type":"disabled"}} 关掉思考；GLM-5.3 强制思考、不能关，用 {"reasoning_effort":"low"} 调轻（low / high / max，默认 max 最慢）。别的厂商写法不同。这一栏单独保存，和 Key 无关。
